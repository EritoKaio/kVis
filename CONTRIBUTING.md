# Contributing

Thanks for your interest in improving kVis!

## Set up the project

Use Node.js `^20.19.0 || >=22.12.0` and npm 10 or later. From the project
directory, install dependencies and start the development server:

```powershell
npm install
npm run dev
```

Run the production build before submitting changes:

```powershell
npm run build
```

## Pull requests

- Keep changes focused and explain the user-visible behavior they affect.
- Include steps to verify your change; mention if it was not practical to test.
- Do not commit `node_modules`, `dist`, local environment files, or credentials.
- Keep project code in modern JavaScript.
